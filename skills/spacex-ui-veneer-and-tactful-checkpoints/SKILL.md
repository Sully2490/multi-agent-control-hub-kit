# SpaceX Engineering Aesthetic & Tactful UI Checkpoints

Apply this skill whenever building or designing a UI, web app, mobile app, slide deck, dashboard, or visual project deliverable.

## 1. Visual Veneer: SpaceX Aerospace Telemetry Aesthetic
Default to a sleek, high-contrast, mission-critical aerospace engineering aesthetic unless the project explicitly requires something else:
- **Palettes:** Deep carbon, obsidian, or orbital navy surfaces paired with sharp, intentional accent colors (e.g., plasma amber/copper, cryogenic cyan, telemetry green) and crisp off-white/titanium silver typography.
- **Typography & Hierarchy:** Clean geometric or condensed display headings paired with precision monospace fonts for metrics, badges, coordinates, formulas, and telemetry callouts.
- **Layout & Density:** Structured telemetry grids, subtle border frames, numbered step cards, high-signal data callouts, and zero visual fluff or generic corporate filler.

## 2. Tactful Decision Checkpoints (Expert-Guided Options)
Do not interrupt the user for trivial details, and do not build an entire visual surface blind when foundational choices will shape the rest of the build:
1. **Identify High-Leverage Inflection Points:** Pause only at decisions that materially influence downstream work (e.g., choosing between two distinct visual/color families, picking the primary layout architecture or storyboard flow, or selecting an interactive component pattern).
2. **Present Concrete, Visual Options:** Provide 2–3 distinct, well-crafted options (with rendered previews, screenshots, or clear side-by-side tradeoffs when applicable) rather than open-ended questions.
3. **Lead with an Expert Recommendation:** State which option best fits the project's goal and why, so the user can either approve the recommendation in one click/word or pick an alternative.
4. **Execute Autonomously Between Checkpoints:** Once a direction is chosen, handle all low-level implementation details, spacing, and polish without asking.
