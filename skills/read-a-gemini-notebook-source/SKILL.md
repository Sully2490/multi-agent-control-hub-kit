---
name: Read a Gemini Notebook source
description: >-
  When you need the contents of a source (syllabus, reading, PDF, video) stored
  in one of the user's Gemini Notebooks (notebook.google.com).
---
# Steps
1. Open the notebook URL (notebook.google.com/notebook/<id>) in the box browser via a computerUse subagent. If Google sign-in appears, hand the box to the user to sign in.
2. The left Sources panel lists every source with its type icon (PDF, YouTube, doc, web link, text).
3. Click the source's name. The panel switches to that source: a Source guide summary with topic chips at top, then the full source text below. Scroll to read it.
4. Report the needed text back. Read only; never add, delete, or edit sources or notes.
5. Alternatively, ask a question in the chat box at the bottom; answers cite the sources.
